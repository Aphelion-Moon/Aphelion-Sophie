# Sophie — selected neon chibi protogen assets

Four original PNGs: avatar, station-service-desk banner, transparent welcoming character cutout, and transparent SOPHIE / Community Services wordmark. Files are copied without alteration. Paths, sizes, alpha metadata, source identifiers and hashes are in asset-manifest.json.

These supersede the earlier human design for active Sophie branding. Read chapter 12 of the v1.1 planning pack for placement, fallbacks, publication review and the no-AI-in-tickets boundary. Assets are static artwork and do not introduce runtime AI assistance or image generation. The FOSS software MIT rule does not assign an artwork licence by implication. No font files, editable vector/layered sources, production-ready sticker exports or additional poses are included.
